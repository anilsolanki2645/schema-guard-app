Frequently Asked Questions

How does Schema Guard block broken database migrations?

Schema Guard acts as a gatekeeper in your CI/CD pipelines (GitHub Actions, GitLab CI, Airflow). Before your DDL migration or pipeline executes, it validates the proposed schema against your locked contract baseline. If breaking changes (such as dropped columns, incompatible type changes, or nullability shifts) are detected, the gate fails immediately with non-zero exit codes.

Are our database credentials safe?

Yes. All database connection strings are encrypted at rest using Fernet AES-128 cryptographic keys. Plaintext passwords are automatically masked with asterisks in all UI views and API serialization responses. Additionally, Schema Guard uses lazy connection pooling that disconnects immediately after catalog metadata extraction.

Can I cancel or upgrade anytime?

Absolutely. Subscriptions are billed monthly with no lock-in. You can upgrade, downgrade, or cancel directly from your Stripe Billing Customer Portal at any moment.
